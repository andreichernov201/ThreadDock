# Приёмка на сервере с сетью

Автоматические тесты не заменяют проверку доступа конкретного сервера к сайтам.
Пункты ниже остаются открытыми до живого прогона.

- [ ] `docker compose up -d --build`; контейнер становится healthy.
- [ ] `/start` и `/help` в личке; ссылка с дополнительным текстом.
- [ ] По одному доступному видео со звуком: TikTok, Instagram Reels, YouTube,
      YouTube Shorts, VK Видео, VK Клипы, X.
- [ ] TikTok Photo Mode: одна фотография с музыкой, несколько с музыкой,
      публикация без музыки. Проверить порядок, длительность, фото-оригиналы и аудио.
- [ ] Две ссылки в одном сообщении; сообщения из двух чатов параллельно.
- [ ] Повтор ссылки использует кеш и Telegram file_id.
- [ ] Удалённая и закрытая публикации дают понятный отказ, остальные задачи продолжаются.
- [ ] `/enable` доступен только администратору группы; обычная ссылка получает
      ответ на исходное сообщение и в той же теме; `/disable` отзывает доступ.
- [ ] Business Connection получает входящие из разрешённых чатов, отвечает в том
      же соединении; исходящие владельца/бота не вызывают повтор.
- [ ] Отключение Business Connection и права ответа прекращают отправку.
- [ ] Перезапуск во время скачивания восстанавливает задачу; во время неопределённой
      отправки не вызывает автоматического дублирования.
- [ ] На диске не остаются временные cookies, metadata JSON и незавершённые задачи;
      кеш удаляется по TTL/лимиту, постоянный том переживает пересоздание контейнера.
- [ ] HTTPS и кнопка Mini App открывают собственный архив; второй аккаунт не видит чужие записи.
- [ ] Новое Business-сообщение, две правки и удаление: полная доступная история и поиск старого текста.
- [ ] Защищённое медиа не копируется; обычное сохраняется и открывается, крупное уходит в личную группу.
- [ ] PIN, биометрия на телефоне, автоблокировка после сворачивания, отзыв сессий при смене PIN.
- [ ] Экспорт четырёх форматов приходит владельцу; удаление очищает его базу/файлы и не затрагивает другого владельца.
- [ ] Ответ из приложения приходит от подключённого аккаунта; после отзыва прав или окна 24 часа отклоняется.
- [ ] GitHub CI проходит, production deploy делает резервную копию и ждёт healthy.

Для недоступного источника фиксировать платформу, дату, код ошибки и версию
yt-dlp. Не публиковать токены, cookies, текст переписки и подписанные CDN URL.
