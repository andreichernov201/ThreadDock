# Запуск на VPS с HTTPS

Понадобятся Linux VPS с Docker Engine/Compose и домен. DNS-записи A (и AAAA, только
если IPv6 действительно работает) должны указывать на VPS. Открой входящие TCP
80/443; UDP 443 необязателен. Порт 8080 не открывай наружу.

1. Скопируй проект на VPS без `.env`, локальных данных и виртуального окружения.
2. Скопируй `.env.example` в `.env`, установи права `chmod 600 .env`.
3. Заполни `BOT_TOKEN` и `ARCHIVE_DOMAIN=archive.example.org`. Не добавляй схему или путь.
4. Запусти:

```sh
docker compose -f compose.yaml -f compose.vps.yaml up -d --build
docker compose -f compose.yaml -f compose.vps.yaml ps
```

Caddy автоматически получит сертификат и отправит запросы в приложение. При
старте бот применит команды, описание и кнопку меню Mini App через Bot API.
В BotFather также можно выбрать Main Mini App и указать тот же HTTPS-адрес — это
добавит кнопку запуска в профиль бота. Без этого меню и `/archive` уже работают.

Проверь `https://archive.example.org/healthz`: ответ `{"ok":true}`. Открой бота в
Telegram и `/archive`. Прямое открытие сайта без Telegram даёт только экран входа
и ссылку на демонстрацию, а не доступ к перепискам.

Если HTTPS не появился, проверь DNS, доступность портов и логи Caddy:

```sh
docker compose -f compose.yaml -f compose.vps.yaml logs --tail=100 caddy
docker compose -f compose.yaml -f compose.vps.yaml logs --tail=100 bot
```

База и медиа сохраняются в томе `threaddock-data`; сертификаты — в отдельных томах
Caddy. `docker compose down` сохраняет тома. Не добавляй `-v`, если данные нужны.
Не запускай два экземпляра бота с одним токеном или одной базой.

Обновление: сначала сделай согласованную резервную копию, затем повтори команду
`up -d --build`. SQLite миграция добавляет архивные таблицы и не удаляет кеш/очередь
загрузчика. После миграции откатывать старую программу без восстановления базы
из резервной копии нельзя.

## Локальная разработка

Без домена и Mini App можно пользоваться командами `/archive_on`, `/stats`,
`/export`, `/pause`, `/mute`; события будут сохраняться. HTTP-сервер по умолчанию
слушает только `127.0.0.1:8080`. Оформление: `http://127.0.0.1:8080/?demo=1`.

Для реального Mini App локально нужен доверенный HTTPS-адрес до этого сервера.
Не открывай локальную базу в публичный доступ и не указывай фиктивный адрес.
После изменения `ARCHIVE_PUBLIC_URL` перезапусти бота или выполни:

```sh
uv run python setup_telegram.py
```

Business-подключение и выбор разрешённых переписок делает владелец аккаунта в
самом Telegram. Перечень прав и включение архива описаны в [archive.md](archive.md).
