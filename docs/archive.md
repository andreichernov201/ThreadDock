# Архив ThreadDock

Архив работает через официальный Telegram Business Connection. Каждый владелец
подключает свой аккаунт и видит только свои данные. Загрузчик ссылок использует
прежнюю очередь и кеш; удаление кеша загрузчика не удаляет переписки.

## Возможности

- Лента удалений, правок, специальных вложений и изменений имени или username. Ключевые слова вызывают отдельные уведомления.
- Фильтр по переписке, поиск по версиям архивных событий, сравнение «было → стало», избранное.
- Фото, видео, документы, голосовые и другие доступные Bot API вложения.
- Галерея, локальный просмотр небольших файлов, запрос оригинала в личный чат бота.
- Копии медиа в отдельной закрытой Telegram-группе с темами по собеседникам.
- Уведомления о правках/удалениях, ключевые слова и исключения, тихие часы, отключение уведомлений по чату.
- Статистика, активность по дням/часам, задержки удалений, выбор периода.
- Экспорт ZIP включает записи в JSON, CSV, Markdown или HTML, локальные вложения и манифест. Большой экспорт делится на ZIP-части; у фрагментов файла в манифесте указано смещение.
- PIN, автоблокировка и биометрия в поддерживаемых клиентах Telegram.
- Пауза, исключение чатов, срок хранения 30/90/365 дней или бессрочно, удаление записей и своего архива.

## Статистика и очистка

По истечении срока хранения и при очистке истории бот убирает переписку,
версии и вложения. Статистика сохраняет время, направление и размеры сообщений,
количество правок и удалений, а также число и размеры файлов по типам.
Частые слова считаются по оставшимся текстам. Счётчики сохранённых файлов
показывают текущие локальные копии.

В настройках можно отдельно сбросить статистику. Счётчики начнутся заново с
новых сообщений, сохранённая переписка останется доступна. Полное удаление
данных удаляет также статистику.

Архив по умолчанию выключен. Включение требует согласия в приложении или явной
команды `/archive_on`. Группы и каналы этим модулем не архивируются.

## Подключение

1. Запусти бота. Для Mini App нужен HTTPS-адрес: см. [VPS](vps.md).
2. В BotFather включи Business Mode для своего бота, если он ещё выключен.
3. В Telegram открой настройки автоматизации чатов / Telegram Business → чат-боты.
   Подключи бота и выбери конкретные разрешённые личные переписки.
4. Разреши ответы, если нужен загрузчик в подключённых переписках. Право чтения
   сообщений требуется только для опционального автоматического прочтения.
5. В личном чате с ботом открой `/archive`, подтверди включение. Отправь новое
   сообщение в разрешённой переписке, затем измени или удали его: событие появится в приложении.
6. По желанию установи PIN и подключи личную группу-хранилище в настройках архива.

Телефон не обязан оставаться разблокированным: события получает сервер бота.
Доступность автоматизации зависит от возможностей и настроек самого Telegram.
Бот не получает старую историю до подключения. Неизвестное удаление отображается
как факт удаления без выдуманного содержимого. Медиа, для которых Telegram не передал file_id или запретил getFile, не восстанавливаются.

## Хранение и безопасность

Тексты, версии, индексы поиска и задания находятся в SQLite. Файлы — в `DATA_DIR/archive`.
Служебная база и файлы должны резервироваться вместе. Для согласованной копии
останови приложение перед копированием тома; не копируй один SQLite-файл при
работающем WAL. При восстановлении сначала останови текущий экземпляр.

Доступ к API проверяется по подписанному Telegram `initData`, затем по короткой
серверной сессии. Токены находятся в памяти страницы; в URL и localStorage их нет.
Все операции проверяют владельца на сервере. Изменяющие запросы требуют CSRF-токен.
PIN хранится как солёный PBKDF2-хеш, попытки ограничиваются на уровне владельца.
Биометрия разблокирует сохранённый Telegram секрет устройства; одного результата
клиентского `true` серверу недостаточно.

PIN защищает вход в приложение, но не шифрует SQLite и не защищает от администратора
VPS. Это не сквозное шифрование. HTTPS защищает передачу; защиту диска и резервных
копий обеспечивает владелец сервера. Уведомления по умолчанию скрывают текст сообщений.

Cloud Bot API скачивает через `getFile` только файлы до 20 MB. Более крупные файлы
можно переиспользовать по `file_id` и сохранять в личную группу; срок доступности
исходного `file_id` Telegram не гарантирует. Если Telegram передал file_id защищённого вложения, бот пробует официальный getFile. При отказе сохраняется явный статус «protected». Успешно сохранённый локальный файл доступен владельцу; защищённые вложения не пересылаются в группу. При заполнении бюджета или недостатке места сохранение новых локальных
файлов останавливается, уже сохранённые данные не вытесняются автоматически.

Группа-хранилище должна быть закрытой, с темами, только с владельцем и ботом.
Бот проверяет состав перед копированием. Не добавляй туда посторонних: уже
отправленные копии доступны участникам группы. При очистке или /optout бот
удаляет локальные записи и ставит известные копии группы в очередь на удаление.
Telegram ограничивает удаление, в том числе по возрасту сообщения (48 часов).
Копии вне учёта, уведомления, отправленные экспорты и резервные архивы удаляются
вручную. Перед восстановлением старой копии повторно примени удаления и исключения
авторов, выполненные после её создания, до возобновления доступа к архиву.

Автопрочтение выключено по умолчанию и требует отдельного права.

## Модули

| Файл | Ответственность |
| --- | --- |
| `handlers/archive.py` | Telegram-события и команды |
| `archive/repository.py` | SQLite, изоляция владельцев, история и поиск |
| `archive/service.py` | Долговечная очередь, уведомления, медиа, экспорт, очистка |
| `archive/auth.py` | Проверка Telegram и PIN |
| `archive/web.py` | HTTP API и проверка доступа |
| `archive/web/app.js` | Состояние и поведение Mini App |
| `core/texts.py` | Все пользовательские сообщения Python/Telegram |
| `archive/web/texts.js` | Тексты и шаблоны интерфейса Mini App |

При сетевом сбое после отправки медиа в личный чат результат может остаться
неизвестным. Задача получает статус `uncertain`. В Mini App можно проверить
чат с ботом и подтвердить повтор. Одно подтверждение создаёт одну новую задачу,
а повторные нажатия возвращают её же. Неопределённый результат сам по себе
новую отправку не запускает, в том числе после перезапуска.

Для просмотра оформления без реальных переписок открой `/?demo=1`. Демо использует
только вымышленные данные в браузере и не отключает авторизацию серверного API.

Вдохновение по функциям: [tg-message-archive](https://github.com/dendy142/tg-message-archive).
Реализация ThreadDock написана на Python и не зависит от его сервиса или платных тарифов.


## Что вызывает уведомление

| Событие | Причина |
| --- | --- |
| Удаление | Telegram прислал deleted_business_messages. Бот показывает последнюю сохранённую версию. |
| Правка | Изменились текст или вложение. В архиве остаются предыдущие версии. |
| Ключевое слово | Совпало слово из списка во входящем сообщении. В уведомлении указано совпадение. |
| Исчезающее вложение | Доступная версия содержит явный признак таймера или одноразового просмотра. |
| Защищённое вложение | Telegram передал признак защиты от пересылки. |

Изменения имени и username видны в ленте архива. Уведомления открывают запись,
если настроен Mini App. При PIN сначала требуется разблокировка. Уведомления по ключевым словам показывают совпадение
отдельно. При отключённой настройке скрытия текста правки содержат краткие
«Было» и «Стало». Если оригинал не пришёл, в правке показывается только
полученная версия с явным статусом исходной.

## Глобальное исключение автора

`/optout` в личном чате с ботом запрещает сохранять сообщения отправителя для
всех владельцев. Проверка выполняется до извлечения содержимого в сервисе и
повторно перед записью в репозитории. Существующие записи автора, версии,
поисковый индекс и локальные вложения удаляются. `/optin` разрешает сохранять
новые сообщения, не восстанавливая старую историю. Копии и уже полученные
экспорты в Telegram, а также резервные копии удаляются отдельно.

## Публичный Mini App

`ARCHIVE_DOMAIN` задаёт адрес `https://<домен>`; при явном `ARCHIVE_PUBLIC_URL`
домен должен совпадать. Production-деплой автоматически включает профиль web
при заданном ARCHIVE_DOMAIN. Маркер web.enabled поддерживается для прежних
установок. Проверка `scripts/check_web.py` проверяет публичный HTTPS, HTML,
JavaScript и отказ неавторизованному API-запросу. Неудачная проверка не объявляет
публикацию успешной. До DNS и HTTPS публичная кнопка работать не сможет.

## Политика медиа

При получении обычного сообщения бот сразу записывает исходный текст и file_id
для обнаружения будущих правок и удалений. Доступные вложения выбранных типов
могут попасть во временный кеш `DATA_DIR/archive/cache` на срок до 72 часов
с момента скачивания. Кеш отделён от архива, скрыт в Mini App и исключён из
полной резервной копии. При нехватке места бот освобождает временные копии в
пользу архивных вложений.

Если правка или удаление произошли до истечения TTL, бот переносит файл из кеша
в постоянное хранилище без повторного скачивания. По истечении TTL локальная
временная копия удаляется, а file_id сохраняется для новой попытки скачивания
при архивном событии. Постоянные файлы подчиняются сроку хранения архива.
В Telegram-хранилище попадают только разрешённые архивные вложения.
Для Live Photo бот сохраняет фото и короткое видео, если Telegram передал
оба компонента. Этот тип включён в стандартный набор медиа. Ключевые слова сами
по себе не открывают запись в архиве.

Подтверждённое исчезающее медиа обрабатывается в отдельной приоритетной очереди
сразу после поступления file_id. Очередь скачивает до двух вложений параллельно
через getFile.
Содержимое доступно даже без открытия сообщения получателем, если Telegram
передал file_id и разрешил скачивание до истечения срока. Вложение может прийти
в самом сообщении или в reply_to_message. Telegram может пропустить отдельное
обновление для одноразового файла. Если доступное защищённое вложение пришло
внутри ответа, бот ставит его скачивание в приоритетную очередь. Сохранённую копию исчезающего файла
можно запросить в личный чат с ботом, если Telegram не пометил исходное
сообщение как защищённое от пересылки. В группу-хранилище исчезающие вложения
автоматически не отправляются. Обычный ответ сам по себе архивного события
не создаёт. Если Telegram скрыл сообщение или файл либо скачивание превысило
лимит, полного оригинала не будет.

Загрузчик ссылок обрабатывает текстовые сообщения. Готовое вложение с URL или
скрытой ссылкой в подписи не запускает повторное скачивание.
