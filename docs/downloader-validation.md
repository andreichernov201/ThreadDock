# Проверка загрузчика — 2026-11-18

Требование: извлечение, загрузка и обработка на своём сервере, без hosted
resolver/downloader API. Ранее добавленные обращения к стороннему сервису удалены.

## Причины задержек

- Instagram job 47: три попытки, отказ через 23 секунды.
- TikTok job 48: 24-минутный ролик; около 34 минут до отказа. Повторялись скачивания,
  конвертации одного файла по разным URL, цепочка загрузчиков и очередь.
- TikTok jobs 46/52/53: успешная доставка за 219/133/90 секунд.
- Webapp-prime CDN отвечает 403; www playback иногда возвращает HTML 404 с HTTP 200.

## Новый путь

Только TikTok `/player/api/v1/items?item_ids=...&aid=1988`, проверка ID и status_code.
Подписанный playback URL с неизменным query обслуживает собственный
`api16-normal-useast8.tiktokv.us`; редиректы/CDN проходят PublicHttp и SafeProxy.
H.264 приоритетнее HEVC. После получения валидного файла конвертация выполняется
один раз, вне цикла адресов. Oversize input сразу адаптируется под транспортный
лимит, с уменьшением разрешения/fps при низком битрейте. CLI ограничены deadline
45 секунд и не повторяют запросы внутри процесса. Повторы принадлежат очереди.
Ошибки лимитов и конвертации не перезапускают загрузчики; таймаут FFmpeg —
отдельный неретрайный processing_timeout.

## Общий предел запроса — последующее уточнение 2026-11-18

Пользователь выбрал максимум 1 минуту при целевой скорости 5–20 секунд.
`REQUEST_TIMEOUT_SECONDS=60` ограничивает ожидание в очереди, извлечение,
скачивание, FFmpeg, fallback, автоматические повторы и отправку одним сроком.
`jobs.requested_at` сохраняется в SQLite; миграция старых задач сохраняет
исходный created_at, не давая старому backlog новый срок после перезапуска.
Только явный новый запрос/кнопка пользователя начинает новый срок.

Перед каждой пачкой Telegram и повтором stale file_id проверяется оставшееся
время. Таймаут обработки отменяет дочерний процесс и запрещает поздний результат.
Таймаут во время upload сохраняется как uncertain без автоматического повтора:
уже принятый сервером Telegram запрос невозможно отозвать. Все подтверждённые
квитанции сохраняются; таймаут необязательной клавиатуры не отменяет факт доставки.

Реальная проверка в изолированном контейнере на VPS: временная БД, свежие ссылки,
штатные очередь/HTTP/FFmpeg, Telegram-отправка заменена spy и не выполнялась:

- Медленный 24-минутный TikTok: request_expired через 60,04 с; 0 вызовов отправки,
  work-каталог очищен, автоматического продолжения нет.
- Короткий TikTok: подготовлен за 5,31 с, очередь дошла до отправки в пределах срока.

Полный локальный прогон: 260 Python tests, FFmpeg/ffprobe, Deno и Chromium.
Добавлены проверки миграции, очереди, нового срока только для явного повторения,
отмены обработки, неопределённого upload и запрета следующей просроченной пачки.
Долгие ролики не пересылаются повторно для приёмки этой версии.
